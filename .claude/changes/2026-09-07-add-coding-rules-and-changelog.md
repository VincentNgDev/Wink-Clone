## What

- Added `.claude/rules/folder-structure.md` — MVVM package layout guidance for the app.
- Added `.claude/rules/coding-style.md` — Kotlin/Android naming, formatting, and idiom
  conventions.
- Added a "Change log" section to `CLAUDE.md` requiring a changelog entry under
  `.claude/changes/` for every future change.

## Why

The user is new to both Android and Kotlin and wanted a documented coding standard to
learn from, plus a lightweight changelog so future changes are traceable without relying
on git history (none exists yet in this repo).

## Follow-up / limitations

None. These are documentation-only changes; no app code was touched.
